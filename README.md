Vice City Nights — an offline web app that turns your photos and a caption into GTA 6-style multi-panel cover art (Vice City sunset and neon grades) and exports it as PNG in common post sizes. Photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — upload photos, pick a layout and grade, edit the caption, and export PNG at 1080×1080, 1080×1350, or 1920×1080.
